# 📄 웹앱 기획 및 과제 제출 문서 (PRD)

---
## 📑 PRD (제품 요구사항 정의서)

### 1. 프로젝트 개요 (Project Overview)
* **프로젝트명:** 나의 건강 지표 계산기 (My Health Metrics Calculator)
* **목적:** 사용자가 자신의 신체 수치를 입력하여 주요 건강 지표(비만도, BMI, 복부비만도)를 쉽고 빠르게 확인할 수 있는 직관적인 웹 애플리케이션 개발.

### 2. 주요 기능 요구사항 (Functional Requirements)
* **기능 1: 표준체중과 비만도 계산 (Tab 1)**
  * **Input:** 신장(cm), 현재 체중(kg)
  * **Process:** 
    * 표준체중: 160cm 이상 `(자신의 신장 - 100) x 0.9` / 150~160cm 미만 `[(자신의 신장 - 150) x 0.5] + 50` / 150cm 미만 `자신의 신장 - 100`
    * 비만도(%): `(현재체중 / 표준체중) X 100`
  * **Output:** 계산된 표준체중과 비만도 수치 출력
* **기능 2: 체질량 지수(BMI) 계산 (Tab 2)**
  * **Input:** 신장(cm), 체중(kg)
  * **Process:** BMI = `체중(kg) / 신장²(m²)` (입력받은 cm 단위를 m로 변환하여 계산)
  * **Output:** BMI 지수 출력
* **기능 3: 허리 엉덩이 둘레비 (WHR) 계산 (Tab 3)**
  * **Input:** 허리 둘레(cm), 엉덩이 둘레(cm)
  * **Process:** WHR = `허리둘레 / 엉덩이둘레`
  * **Output:** 복부비만도(WHR) 수치 출력

### 3. 비기능 요구사항 (Non-Functional Requirements)
* **UI/UX:** PC와 모바일 환경을 모두 지원하는 반응형 웹 디자인 적용 및 직관적인 탭(Tab) 메뉴 구성.
* **예외 처리:** 입력창 누락 및 숫자 외 문자 입력 시 에러 메시지(경고창) 출력.
* **성능:** Client-side rendering을 통해 페이지 새로고침 없이 즉각적으로 결과 도출.
* **배포:** GitHub 리포지토리를 경유하여 Vercel을 통해 무료 호스팅 배포.

### 4. 제약 사항 및 향후 계획
* **제약 사항:** 본 웹앱의 결과는 단순 참고용 지표이며, 의학적 진단을 대체하지 않음을 명시.
* **향후 계획 (V2):** 계산된 수치에 따라 정상/과체중/비만 등의 상태를 색상(초록, 노랑, 빨강)으로 시각화하는 기능 추가.
